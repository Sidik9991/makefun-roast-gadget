One original line roasting a gadget used every day: "My laptop charger works at exactly one angle, so every morning I perform surgery on a cable." — the charger only works at one magic angle, so each morning becomes an operation. Entry for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty ($5 top 3). The program writes the line to /output/entry.txt.

## Run it

```sh
node main.ts
```
